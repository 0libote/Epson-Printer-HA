Windows 11

  1. Settings → Bluetooth & devices → Printers & scanners.
  2. Try Add device first.
  3. If it is not found, choose the manual add option and enter {{ client_setup.http_uri }}.
  4. Use the Microsoft IPP class driver when Windows offers it.

macOS

  1. System Settings → Printers & Scanners → Add Printer.
  2. Look for {{ display_name }} in the default/Bonjour list.
  3. If needed, use the IP tab with protocol IPP, address {{ client_setup.host }} and queue /{{ client_setup.queue_path }}.

iPhone / iPad / Linux

Apple devices can use Bonjour/IPP discovery when the queue is advertised. Linux desktops can add the IPP URI directly. If a device cannot discover the printer, use the IPP address above.
